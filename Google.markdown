# Google Specific Instructions

## Install Mule software

```
./mule.sh
```

### Configure fish-shell as default

```
chsh -s /usr/local/bin/fish
```

## Install dotfiles

```
./install.sh | yes
```

## Install Homebrew

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Install Brewfile

```
# cd ~/dotfiles
brew bundle
```
